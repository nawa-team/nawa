# نَوء

المحاضرة والكود في شاشة واحدة. تطبيق قابل للتثبيت (PWA) لمتدربي البرمجة في الكليات التقنية.

- شرائح المحاضرة (PDF) ومحرر HTML/CSS/JS مع معاينة حية في شاشة واحدة
- رسالة الخطأ بالإنجليزي، مع شرح وتلميح بالعربي بدون الحل
- المدرب يرفع المحاضرة، والذكاء الاصطناعي يقترح المواضيع والتمارين، والمدرب يراجع ويقرر
- قياس نسبة الكتابة اليدوية، والحل أثناء المحاضرة، ووقت الحل، والأخطاء الشائعة

## التقنيات
- واجهة ثابتة بدون أدوات بناء (ES modules)
- Supabase: قاعدة البيانات وتسجيل الدخول والتخزين، مع Row Level Security على كل جدول
- Edge Function تستدعي Gemini، ومفتاحها محفوظ كسرّ داخل Supabase فقط

## الخصوصية
- لا توجد أي مفاتيح سرية في هذا المستودع. المفتاح في `js/config.js` عام بطبيعته، والبيانات محمية بسياسات RLS.
- النسخة التجريبية تستخدم بيانات وهمية فقط، ولا تُرسل أسماء أو بريد للذكاء الاصطناعي.

مشروع مقدّم لمبادرة ربان للذكاء الاصطناعي، 2026.
