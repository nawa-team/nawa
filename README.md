# نَوء

**تنتهي الشريحة، ويبدأ الكود.**

نَوء منصّة تحوّل محاضرة البرمجة إلى تطبيق فوري. تظهر الشريحة والمحرر ونتيجة الكود معًا في شاشة واحدة، فيكتب المتدرب الكود في لحظة الشرح نفسها، ويرى المدرب أثناء المحاضرة من فهم ومن تعثّر، وأين تعثّر الفصل كله. ويساعد الذكاء الاصطناعي في تجهيز التمارين وشرح الأخطاء بالعربية، ويبقى القرار للمدرب دائمًا.

**الرابط الحي:** https://nawa-puce.vercel.app

مشروع مقدّم لمبادرة ربان للذكاء الاصطناعي، 2026. كل البيانات في النسخة التجريبية وهمية.

---

## جرّب نَوء في دقيقتين (للمحكّمين)

1. افتح https://nawa-puce.vercel.app
2. في قسم «تجربة سريعة بدون تسجيل» اضغط **كمدرب** أو **كمتدرب**. لا تحتاج كلمة مرور.

**كمدرب:** افتح الفصل التجريبي، ثم المحاضرة، واضغط «بدء الجلسة المباشرة». تنقّل بين الشرائح، وشاهد نبض الشريحة وخريطة الأخطاء الحرارية. ثم افتح أي تمرين لمراجعة حلول المتدربين الوهميين.

**كمتدرب:** افتح تمرينًا، واكتب الكود بجانب الشريحة، وشاهد النتيجة مباشرة. جرّب خطأً مقصودًا (مثل `<hl>` بدل `<h1>`) لترى رسالة الخطأ والتلميح بالعربية.

**تجربة رفع محاضرة:** استخدم الملف الجاهز [`docs/sample-lecture-html.pdf`](docs/sample-lecture-html.pdf) (محاضرة HTML من 10 شرائح). ارفعه من حساب المدرب، فيستخرج الذكاء الاصطناعي المواضيع ومسودات التمارين، ثم راجعها وأرسلها.

> الفصل التجريبي مقفل عمدًا: لا يمكن حذفه ولا تغيير رمزه ولا حذف محاضرته أو تمارينه أو متدربيه، حتى يجده كل محكّم كما هو. ولتجربة الحذف والتعديل بحرية، أنشئ فصلًا جديدًا من حساب المدرب.

## الميزات

### الأساسية: فكرة نَوء
| الميزة | ما تفعله |
|---|---|
| شاشة واحدة | الشريحة والمحرر ونتيجة الكود معًا، مع معاينة حية في إطار معزول. اللغات: HTML وCSS وJavaScript |
| تمرين الشريحة | كل تمرين مربوط برقم شريحته، فإذا وصل إليها المدرب في الجلسة المباشرة ظهر التمرين لكل المتدربين في اللحظة نفسها |
| نبض الشريحة | زر «لم أفهم» على كل شريحة دون إظهار الاسم. يرى المدرب العدد، ويقترح الذكاء الاصطناعي شرحًا أبسط |
| خريطة الأخطاء الحرارية | نوع الخطأ في كل تمرين وعدد من وقعوا فيه، بألوان الإشارة، وتنبيه بالتوقف والشرح إذا وقع فيه 40% من الفصل أو أكثر |
| شرح الأخطاء | فاحص خاص لأخطاء HTML (لا يُظهرها المتصفح)، ورسالة الخطأ الأصلية بالإنجليزية مع رقم السطر، ومعها تلميح بالعربية دون الحل |
| تمارين من المحاضرة | يرفع المدرب ملف PDF، فيقترح الذكاء الاصطناعي المواضيع ومسودات التمارين، والمدرب يعدّل ويضيف ويقرر الإرسال |
| تقييم حسب المطلوب | يقترح الذكاء الاصطناعي تقييمًا حسب الناتج والمفهوم المطلوب، وإذا كان الحل بطريقة غير المطلوبة اقترح «صحيح جزئيًا». والقرار للمدرب |
| نسبة الكتابة اليدوية | ما كتبه المتدرب بيده مقابل ما لصقه، مع وقت الحل، في لوحة الالتزام للمدرب |

### الإضافية: للاستخدام اليومي
تطبيق قابل للتثبيت (PWA) ونسخة APK لأندرويد، وحفظ تلقائي للحل كل 5 ثوانٍ، وملاحظات المدرب، واختبارات تدريبية لا تُحتسب في الدرجة، وإدارة الفصل والمحاضرات، وتلوين الكود وأرقام الأسطر، والوضع الفاتح والداكن، واستعادة كلمة المرور.

## الذكاء الاصطناعي: يقترح، والمدرب يقرر

النموذج: Google Gemini (`gemini-flash-lite`، واحتياطيًا `gemini-flash`)، عبر دالة خادم تحفظ المفتاح بعيدًا عن المتصفح.

| المهمة | ماذا يفعل الذكاء الاصطناعي | القرار البشري |
|---|---|---|
| مواضيع المحاضرة | يستخرج من 3 إلى 8 مواضيع مع رقم الشريحة | المدرب يختار |
| التمارين | يكتب مسودة لكل موضوع | المدرب يعدّل أو يحذف أو يضيف، ثم يرسل |
| التقييم | يقترح «صحيح» أو «صحيح جزئيًا» أو «يحتاج مراجعة» | المدرب يعتمد أو يغيّر |
| شرح الخطأ | يشرح بالعربية ويعطي تلميحًا دون الحل | المتدرب يصلح بنفسه |
| نبض الشريحة | يقترح شرحًا أبسط للشريحة | المدرب يقرر هل يستخدمه |
| التدريب | اختبار قصير من 5 أسئلة | لا يُحتسب في الدرجة |

لا يُرسَل للذكاء الاصطناعي أي اسم أو بريد، فقط نص المحاضرة والتمرين والكود ورسالة الخطأ.

## التقنيات (كلها في خططها المجانية)
- **الواجهة:** ملفات ثابتة بدون أدوات بناء (ES modules)، مستضافة على **Vercel**، وعرض الشرائح بـ **PDF.js**.
- **Supabase:** قاعدة بيانات PostgreSQL من 10 جداول عليها كلها Row Level Security، وتسجيل الدخول، وتخزين خاص للمحاضرات، وتحديث لحظي (Realtime).
- **Edge Functions:** الدالة `ai` تستدعي Gemini ومفتاحها سرّ داخل Supabase، والدالة `demo` تُدخل الحسابين التجريبيين برابط لمرة واحدة.

## هيكل المستودع
```
index.html, styles.css, sw.js, manifest.webmanifest   الواجهة وملفات التطبيق
js/app.js        الصفحات والتنقل
js/workspace.js  المحرر والمعاينة وكشف الأخطاء
js/heat.js       خريطة الأخطاء الحرارية
js/pdf.js        عرض شرائح المحاضرة
js/lib.js        الاتصال بـ Supabase ورسائل الأخطاء
js/config.js     الإعدادات العامة فقط (رابط المشروع والمفتاح العام)
supabase/migrations   الجداول والسياسات والدوال
supabase/functions    دوال الخادم (ai, demo)
docs/                 محاضرة تجريبية للرفع
.well-known/          ربط نسخة أندرويد بالموقع
```

## التشغيل محليًا
1. انسخ المستودع، ثم شغّل خادمًا بسيطًا من مجلده:
   ```
   python3 -m http.server 8080
   ```
2. افتح `http://localhost:8080`. سيتصل التطبيق بمشروع Supabase المذكور في `js/config.js`.

## التشغيل على مشروع Supabase جديد
1. أنشئ مشروعًا مجانيًا في Supabase.
2. نفّذ ملفات `supabase/migrations` بالترتيب في SQL Editor.
3. عيّن رمز اعتماد المدربين (لا تضعه في أي ملف):
   ```sql
   update private.settings set value = '<رمز من اختيارك>' where key = 'trainer_code';
   ```
4. انشر الدالتين:
   ```
   supabase functions deploy ai
   supabase functions deploy demo --no-verify-jwt
   ```
5. أضف السر: `supabase secrets set GEMINI_API_KEY=<مفتاحك>`
6. ضع رابط المشروع والمفتاح العام (publishable) في `js/config.js`.
7. في Authentication ← URL Configuration اجعل Site URL رابط موقعك.
8. ارفع المجلد إلى Vercel كموقع ثابت، بدون أوامر بناء.

## الخصوصية والأمان
- لا توجد أي مفاتيح سرية في هذا المستودع. المفتاح في `js/config.js` عام بطبيعته، والبيانات محمية بسياسات RLS.
- مفتاح Gemini ومفتاح الخدمة ورمز اعتماد المدربين محفوظة داخل Supabase فقط.
- النسخة التجريبية تستخدم بيانات وهمية فقط.
- كود المتدرب يعمل داخل إطار معزول (iframe بخاصية sandbox)، مع حارس يوقف الحلقات اللانهائية.
- البيانات حاليًا على خوادم Supabase في ألمانيا، وهذا مقبول لأنها وهمية. وعند التشغيل الفعلي تُنقل إلى سحابة داخل المملكة، التزامًا بنظام حماية البيانات الشخصية.

## الإفصاح عن استخدام الذكاء الاصطناعي
- **داخل التطبيق:** Google Gemini لاقتراح المواضيع والتمارين والتقييم، وشرح الأخطاء، والشرح الأبسط للشريحة، والاختبارات القصيرة.
- **في بناء المشروع:** استعان الفريق بـ Claude من Anthropic في كتابة الكود والتصميم والاختبار والمخططات والتوثيق. الفكرة والقرارات والمراجعة والتجربة من الفريق.
