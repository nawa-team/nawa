# نَوء

المحاضرة والكود في شاشة واحدة. تطبيق قابل للتثبيت (PWA) لمتدربي البرمجة في الكليات التقنية.

**الرابط الحي:** https://nawa-puce.vercel.app

## التجربة السريعة (للمحكّمين)
في صفحة البداية قسم «تجربة سريعة بدون تسجيل»:
- **كمدرب:** فصل جاهز فيه محاضرة وتمارين ومتدربون وهميون، ولوحة الالتزام والأداء.
- **كمتدرب:** حل التمارين بجانب شرائح المحاضرة، مع المعاينة الحية وشرح الأخطاء بالعربية.

لا تحتاج كلمة مرور. كل البيانات في الحسابين التجريبيين وهمية.

## المزايا
- شرائح المحاضرة (PDF) ومحرر HTML/CSS/JS مع معاينة حية في شاشة واحدة
- رسالة الخطأ بالإنجليزية كما هي، مع شرح وتلميح بالعربية دون إعطاء الحل
- المدرب يرفع المحاضرة، والذكاء الاصطناعي يقترح المواضيع والتمارين، والمدرب يراجع ويقرر
- الذكاء الاصطناعي يقترح تقييمًا للحل، والمدرب يعتمده أو يغيّره
- قياس نسبة الكتابة اليدوية، والحل أثناء المحاضرة، ووقت الحل، والأخطاء الشائعة
- متابعة الشريحة مع المدرب لحظيًا، وملاحظات المدرب للمتدرب
- رمز الفصل يمكن تغييره، والمدرب يستطيع إزالة متدرب من الفصل

## التقنيات
- واجهة ثابتة بدون أدوات بناء (ES modules)، ومستضافة على Vercel
- Supabase: قاعدة البيانات وتسجيل الدخول والتخزين، مع Row Level Security على كل جدول
- Edge Function باسم `ai` تستدعي Gemini، ومفتاحها محفوظ كسرّ داخل Supabase فقط
- Edge Function باسم `demo` لتسجيل الدخول للحسابين التجريبيين برابط لمرة واحدة

## هيكل المستودع
```
index.html, styles.css, sw.js, manifest.webmanifest   الواجهة وملفات التطبيق
js/app.js        الصفحات والتنقل
js/workspace.js  المحرر والمعاينة وكشف الأخطاء
js/pdf.js        عرض شرائح المحاضرة
js/lib.js        الاتصال بـ Supabase ورسائل الأخطاء
js/config.js     الإعدادات العامة فقط (رابط المشروع والمفتاح العام)
supabase/migrations   الجداول والسياسات والدوال
supabase/functions    دوال الخادم (ai, demo)
```

## التشغيل محليًا
1. انسخ المستودع، ثم شغّل خادمًا بسيطًا من مجلده:
   ```
   python3 -m http.server 8080
   ```
2. افتح `http://localhost:8080`. سيتصل التطبيق بمشروع Supabase المذكور في `js/config.js`.

## التشغيل على مشروع Supabase جديد
1. أنشئ مشروعًا مجانيًا في Supabase.
2. نفّذ ملفات `supabase/migrations` بالترتيب في SQL Editor.
3. عيّن رمز اعتماد المدربين (لا تضعه في أي ملف):
   ```sql
   update private.settings set value = '<رمز من اختيارك>' where key = 'trainer_code';
   ```
4. انشر الدالتين:
   ```
   supabase functions deploy ai
   supabase functions deploy demo --no-verify-jwt
   ```
5. أضف السر: `supabase secrets set GEMINI_API_KEY=<مفتاحك>`
6. ضع رابط المشروع والمفتاح العام (publishable) في `js/config.js`.
7. في Authentication ← URL Configuration اجعل Site URL رابط موقعك.
8. ارفع المجلد إلى Vercel كموقع ثابت، بدون أوامر بناء.

## الخصوصية والأمان
- لا توجد أي مفاتيح سرية في هذا المستودع. المفتاح في `js/config.js` عام بطبيعته، والبيانات محمية بسياسات RLS.
- مفتاح Gemini ومفتاح الخدمة ورمز اعتماد المدربين محفوظة داخل Supabase فقط.
- النسخة التجريبية تستخدم بيانات وهمية فقط، ولا تُرسل أسماء أو بريد إلى الذكاء الاصطناعي.
- كود المتدرب يعمل داخل إطار معزول (sandbox)، مع حماية من الحلقات اللانهائية.
- الذكاء الاصطناعي يساعد فقط، والقرار النهائي للمدرب.

## الإفصاح عن استخدام الذكاء الاصطناعي
- **داخل التطبيق:** يستخدم Gemini لاقتراح مواضيع المحاضرة والتمارين، واقتراح تقييم الحلول، وشرح الأخطاء بالعربية.
- **في بناء المشروع:** استعان الفريق بـ Claude (من Anthropic) في كتابة الكود والتصميم والاختبار والتوثيق. الفكرة والقرارات والمراجعة والتجربة من الفريق.

مشروع مقدّم لمبادرة ربان للذكاء الاصطناعي، 2026.
